## בדיקות ושמירה על התנהגות

- נבדקו 12 מסלולי התחלה: שש מנות בכל אחד משני רוחבי המסך. רכיבים וכמות מוצגים לפני פעולה; נדרש אישור מפורש, וביטול החלון אינו מתחיל בישול.
- נבדקו הקלדה ושליחת שאלה, חסימת התחלת סלמון כשמדווחת אלרגיה לדגים, דיווח טמפרטורה גלוי והופעת כפתור הסיום.
- נבדקו פתיחת יומן הפעולות המוטמע, פתיחת פעולת חיתוך וביטולה, ושחרור העמוד הראשי לאחר סגירת חלון היומן.
- נשמרו פקודת התחנה בת ששת הבלוקים, הצגת אזהרות, מילון המונחים וייצוא Obsidian. בדיקת התחנה עברה במחשב ובמובייל.
- שש בדיקות השער וה־Worker עברו, וכן בדיקות תחביר JavaScript ו־Ruff לכלי הבדיקה החדשים. לא שונה קוד Python של החלטות הבישול בהרחבת העיצוב הזאת.
- בבדיקות המקומיות לא נמצאו שגיאות JavaScript או גלילה אופקית בשני רוחבי המסך. נבדקו יציאה מהחלון עם Escape והחזרת המיקוד לכפתור הפותח.

כלי הבדיקה: `scripts/check_experience_browser.py`. הוא תומך בבדיקה מקומית מבודדת וב־`--url` לבדיקת אותו מסלול כאורח באתר הציבורי. צילומי לפני/אחרי ותוצאות: `C:/workspace/.runtime/chef-ux-review-20261106`.

## תמונת הרקע

נוצרה באמצעות כלי **imagegen המובנה**, ללא שימוש ב־CLI או במפתח API מקומי. הקובץ באתר: `backend/app/static/kitchen-background.webp`, בגודל כ־335 KB. הוא מכיל ערוץ שקיפות אמיתי ומוצג ב־CSS בעוצמה של 22%; הטקסט והכפתורים יושבים על משטחים בהירים. נשמר עותק PNG מקורי בתוצרי הבדיקה. בוצעה המרת פורמט בלבד, ללא שינוי הקומפוזיציה.

Wide landscape composition. Refined editorial interior photography with soft feathered transparent edges; mostly negative/transparent space so interface text remains readable above it. No people, no text, no lettering, no logo, no watermark. Genuine transparent alpha background, keep the kitchen elements softly isolated and concentrated towards the outer edges and lower portion.
