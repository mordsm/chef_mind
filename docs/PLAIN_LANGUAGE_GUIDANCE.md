# שפת ההנחיות

הוראות הבישול נכתבות במילים יומיומיות: מה לעשות, במה להשתמש,
כמה זמן לתכנן, מה לבדוק ומתי לסיים. גם התיבול מתואר כפעולה שאפשר לבצע:
״הוסף קמצוץ מלח, ערבב וטעם״, במקום ״אזן מליחות״.

אין להשאיר את המשתמש עם הסתייגות במקום פעולה. אם ההכנה אינה דורשת
השריה, אומרים ״בהכנה הזו אין צורך בהשריה; ייבש ובשל״. לא מסיקים מכך
שהשריה אינה מועילה בכל מתכון אחר.

זמנים משוערים מוצגים עם התנאים שבהם ניתנו. ההערכות אינן הופכות
לאישור בטיחות ואינן מתוארות כבדיקה של המין המסוים אם המקור אינו כזה.

## מילון

המילון נמצא ב־`backend/app/static/culinary-glossary.js`. מוסיפים לכל מונח
שם, שמות חלופיים אם צריך והסבר קצר שאינו דורש ידע קודם. הממשק מסמן
את המונחים המוגדרים בתוך ההנחיות בכפתור מודגש וצבעוני. הקלקה או
הפעלה במקלדת פותחות הסבר; Escape סוגר ומחזיר את המיקוד למונח.
כפתור ״מילון בישול״ מאפשר לעיין בכל המונחים.

המילון מתחיל ב־21 מונחים; הוא אינו מזהה אוטומטית כל מושג מקצועי חדש.
כשמוסיפים מושג חדש להנחיות, מוסיפים גם הסבר למילון, או מחליפים אותו
במילים רגילות. פירוש מונח אינו אישור להפעיל טכניקה בכל מנה.

אחרי עדכון המילון מריצים `node scripts/export_culinary_glossary.cjs`
כדי לעדכן את הפתק המקביל בכספת Obsidian.

## מקורות שנשמרו בכספת

- `09_Sources/SRC-FDA-SEAFOOD-CONSUMER.md`: תקציר עברי וקישור למדריך.
- `09_Sources/FDA-Seafood-Consumer-Guide.html`: עותק קריא של טקסט המדריך,
  ללא תמונות או עיצוב מקורי. אפשר לרענן בעזרת `scripts/save_fda_seafood_guide.py`.
- `09_Sources/SRC-FRDC-FISH-POACHING.md`: טבלת זמני ההערכה ותנאיה.
- `00_Ontology/Culinary-Plain-Language-Glossary.md`: המילון המיוצא.

שמירה בכספת אינה מפעילה אוטומטית טענות כמקורות שאושרו באינדקס ההחלטות.
