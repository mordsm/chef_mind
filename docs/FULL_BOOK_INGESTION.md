# קליטה מלאה של שכבת המקור והפרדתה מהערות מעובדות

נקודת הכניסה ב־Obsidian:
`Culinary-Knowledge/09_Sources/Full-Books/Book-Network-Hub.md`.

העותק המלא של Salt, Fat, Acid, Heat נמצא ב־Downloads. כל 593 עמודיו נקלטו.
200 עמודים המכילים תמונות נשמרו כתמונות מקור ועברו OCR מקומי באנגלית.
נוצרו 98 הפניות למתכונים, 22 מפות פרקים ו־27 מפות נושא עם קישורים למושגים
הקיימים. נוספו 48 הערות עבריות מעובדות, שנבדקו מול עוגני טקסט, ושלוש טבלאות
מקור מובנות. ההערות המקוריות נשמרו.

כיסוי העמודים מלא; **אימות כל הטענות, סדר השורות ב־OCR וגבולות כל המתכונים
אינו מלא**. הקובץ `nosrat-coverage.json` מפריד בין כיסוי, OCR, ביטחון נמוך
ובדיקת כללים. מידע שלא תומצת נשמר בדפי המקור, כולל כמויות, חריגים, סיפורי
רקע ומקורות. כל תמונה נשמרת כך ש־OCR שגוי לא מוחק את התוכן החזותי.

לאחר שהמשתמש החזיר את המקורות ל־Downloads, נקלט גם הספר המלא של אסף אביר:
280 דפי מקור, תמונות ו־OCR בעברית ובאנגלית, 10 מפות פרקים, 27 מפות נושא,
46 הפניות לפי רשימת המתכונים של המחבר, 31 הערות מעובדות נוספות ושתי טבלאות
שנבדקו חזותית. רשימת ההפניות כוללת גם הדגמת חושים שאינה מנה למאכל.
סך הכול: 873 דפי מקור, 480 דפים שעברו OCR, 144 הפניות ו־95 הערות מעובדות
כולל 16 ההערות הראשונות. שני קובצי ה־PDF המלאים נשמרים בארכיון המקומי.

הקריאה החוזרת בעמוד 110 תיקנה שגיאה בסבב הראשון: הטבלה כן כוללת זמני
צלייה. הנתונים המעודכנים כוללים כשעה לירקות שורש ב־180°C, כחצי שעה לגיבץ'
ב־180°C, כחצי שעה לרטטוי ב־160°C ותשע דקות לדלעת ב־240°C בתנאי חיתוך
של כחצי סנטימטר. שמות המנות וההרכבים צומצמו לדוגמאות שהטבלה אכן מתארת.

## תחום השימוש והפרסום

כל הרשומות החדשות מסומנות `project_scope: chef_mind`, עם הקשר מורשה לפרויקטים
קולינריים קשורים ו־`external_publication: false`. לא נעשתה העתקה לפרויקט אחר,
פרסום, commit, push או העלאת הספרים לשירות OCR. הורדו רק תוכנת OCR ומודלי שפה.
דפי המקור המלאים והתמונות מוחרגים מ־Git; הם קיימים בכספת המקומית.

אין להסיק מכך רישיון חדש לספרים: חומרם אינו מיוצא דרך מסמך האונטולוגיה
הכללי שמסומן ברישיון CC. העיבודים נשארים מיוחסים למקורותיהם.

## תהליכי עבודה מקומיים

1. `prepare_full_book.py`: חילוץ כל עמוד ב־PyMuPDF, גיבוב מקור ותור תמונות.
2. `book_ocr.cjs`: OCR מקומי בארבעה workers, עם מטמון מודל עברית/אנגלית.
3. `build_book_network.py`: דפי מקור, קישורים לרשת, הפניות ומניפסט כיסוי.
4. `curate_nosrat_network.py`: שחזור 48 העיבודים ובדיקת כל עוגן מקור.
5. `curate_book_tables.py`: שחזור הטבלאות שנבדקו בנפרד.
6. `curate_avir_network.py`: שחזור 31 הערות אסף אביר ושתי הטבלאות החזותיות.

הסקריפט הראשון דורש Python עם PyMuPDF. שאר סקריפטי Python משתמשים ב־PyYAML
שכבר קיים בפרויקט. OCR משתמש בהתקנה המקומית ב־`tmp-book-ocr`, שאינה תלות
של שרת היישום. אין להעלות קובץ ספר לשרת כדי להריץ תהליך זה.

`reviewed-manifest.json` מאפשר למנוע ההסברים לטעון רק את ההערות המעובדות
שהגיבוב שלהן תואם. דפי מקור, הפניות ומתכונים לא עוברים ממנו למסלול ביצוע.
קשרי `MENTIONS` הם ניווט מילולי בלבד. אבחון של רשומת מקור מחזיר
`reference_only`, ולא `ready` לבישול. טבלאות הזמן נועדו לעיון, אינן מקור
לספי בטיחות ואינן מפעילות טיימרים או משלימות מדידות.

המסלול הציבורי לפרטי צומת מחזיר מטא־דאטה של דף מקור ללא תוכנו המלא.
קריאת התוכן המלא דרך API מחייבת התחברות ב־
`GET /v1/ontology/private/nodes/{node_id}`. ב־Obsidian המקומי אפשר לפתוח
את דפי המקור ואת קובצי ה־PDF ללא מסלול השרת.
