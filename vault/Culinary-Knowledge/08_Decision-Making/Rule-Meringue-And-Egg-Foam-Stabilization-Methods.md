# כלל החלטה: בחירת שיטת ייצוב קצף ביצים וסוג המרנג — צרפתי, איטלקי או שווייצרי (`RUL-EGG-004`)

## 1. הצהרת הכלל המותנה (`IF / THEN / BECAUSE / EXCEPTIONS`)
* **IF (תנאי)**: השף מכין קצף חלבונים או מרנג ונדרש להחליט על שיטת הייצוב, מועד הוספת הסוכר וסוג המרנג.
* **THEN (פעולה מומלצת)**:
  1. **בחירת מייצב כימי נגד התגרגרות**: הקצף בקערת נחושת/כסף **או** הוסף בתחילת ההקצפה `0.5 גרם (1/8 כפית) קרם טרטר` או `2 מ"ל (1/2 כפית) מיץ לימון` לכל חלבון ביצה. **אל תוסיף מלח לקצף** (הוסף אותו לבסיס המנה).
  2. **שליטה במרקם דרך מועד הוספת הסוכר**:
     - לקצף אוורירי וקל (למוס/סופלה/ציפוי רך): הקצף תחילה לפסגות יציבות ואז קפל או טרוף פנימה את הסוכר.
     - לקצף צפוף, חלק ונוח לעיצוב וזילוף (או בשיטת ה"טייס האוטומטי" במיקסר): הוסף את הסוכר מוקדם במהלך ההקצפה.
  3. **בחירת סוג המרנג לפי צורכי יציבות ובטיחות מזון**:
     - אם המרנג נאפה מיד — **מרנג צרפתי (Uncooked)**.
     - אם נדרש קצף אוורירי אך יציב ליום-יומיים מראש (מביצים מפוסטרות או ללא דרישת פסטור) — **מרנג איטלקי (Syrup-cooked, סירופ ב-115°C–120°C)**.
     - אם נדרש **פסטור מלא מסלמונלה** במרנג שאינו נאפה לאחר מכן — **מרנג שווייצרי (Swiss / Meringue Cuite, חימום ל-75°C–78°C באמבט מים)**.
* **BECAUSE (נימוק מדעי)**: יוני נחושת ויוני מימן ($\text{H}^+$) מונעים יצירת קשרי גופרית ($\text{S}-\text{S}$) הדוחקים מים מהקצף; סוכר המוסף מוקדם מאט פתיחת חלבונים אך מקטין ומצופף את הבועות; ובמרנג איטלקי הסירופ החם מתקרר במגע עם הקערה והמטרפה כך שהקצף מגיע ל-**55°C–58°C בלבד** (אינו משמיד *Salmonella*), בעוד שבמרנג שווייצרי החימום ההדרגתי באמבט מים עם סוכר וקרם טרטר מאפשר להגיע ל-**75°C–78°C** מבלי להקריש את הקצף (עמ' מודפס 103–108 | PDF עמ' 117–122).
