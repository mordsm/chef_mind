# כמה זמן לבשל דג בנוזל חם?

המדריך מתאר נוזל ב־75–85°C, בכמות שמכסה את הדג. סופרים זמן אחרי
שהנוזל חזר לחום הרצוי. ההערכות לפילה הן:

| עובי | זמן משוער במקור |
| --- | --- |
| 1 ס״מ | 3 דקות |
| 2 ס״מ | 5 דקות |
| 3 ס״מ | 5–8 דקות |

אלה זמני תכנון כלליים. הם משתנים לפי סוג הדג, כמותו, חומו בתחילת
הבישול והכלים. אין במקור בדיקה מסוימת של נסיכת הנילוס עד 63°C
ל־15 שניות. בנוזל ב־70°C יכול להידרש זמן ארוך יותר מההערכות האלו.
השעון אינו מחליף מדידה במרכז הדג.

[המקור וטבלת הזמנים](https://www.fishfiles.com.au/consuming/cooking/poaching).
